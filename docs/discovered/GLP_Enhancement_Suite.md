## 功能介绍

本脚本为 GodlikeProductions 论坛提供深色主题，自动屏蔽广告和弹窗，支持屏蔽指定用户和帖子，折叠引用内容，自动翻页，并简化页面布局。用户可通过高级设置界面自定义功能。

## 适用网站

- GodlikeProductions 论坛

## 使用方法

1. 安装脚本后，访问 GodlikeProductions 论坛页面。
2. 页面会自动应用深色主题并屏蔽广告。
3. 在论坛界面可通过设置按钮进入高级设置，调整各项功能。
4. 可手动屏蔽指定用户或帖子，折叠引用内容。
