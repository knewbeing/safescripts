## 功能介绍

本脚本可让你在 Twitter/X 上一键下载图片和视频，支持自定义文件名，并能记录下载历史。操作简单，方便管理和保存喜欢的媒体内容。

## 适用网站

- Twitter
- X

## 使用方法

1. 安装脚本后，打开 Twitter 或 X 网站。
2. 在推文的图片或视频上会出现下载按钮。
3. 点击下载按钮即可保存媒体文件。
4. 可在设置中自定义文件名格式和查看下载历史。
