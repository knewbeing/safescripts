## 使用方法

1. 安装脚本后，打开X（原Twitter）或Twitter网页。
2. 在推文下方会出现一键保存图片或视频的按钮。
3. 点击按钮即可快速下载所需媒体。
4. 时间显示会自动优化，无需手动设置。
