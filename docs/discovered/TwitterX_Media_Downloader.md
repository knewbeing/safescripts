## 使用方法

1. 安装脚本后，访问 Twitter 或 X 网站。
2. 在推文的图片或视频旁会出现下载按钮。
3. 点击下载按钮即可保存媒体文件。
4. 可在设置中自定义文件名和查看下载历史。
