## 使用方法

1. 安装脚本后，打开 YouTube、YouTube Music 或 YouTube Studio 页面。
2. 在视频页面会看到新增的标签栏，可切换信息、评论、播放列表等。
3. 如需下载视频，点击相应的下载按钮即可。
