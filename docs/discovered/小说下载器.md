## 使用方法

1. 安装脚本后，访问支持的小说网站。
2. 在小说详情页会自动出现下载按钮。
3. 点击下载按钮，选择需要的格式（如TXT、EPUB等）。
4. 等待下载完成，即可保存到本地阅读。
