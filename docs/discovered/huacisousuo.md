## 使用方法

1. 安装脚本后，打开任意HTTPS网页。
2. 用鼠标或手指选中你想搜索的文字。
3. 弹出的搜索菜单会显示不同搜索选项。
4. 点击对应链接即可跳转到相关搜索结果页面。
