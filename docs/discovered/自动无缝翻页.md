## 使用方法

1. 安装脚本后，访问支持的网站。
2. 向下滚动页面，下一页内容会自动加载到网页底部。
3. 无需手动点击“下一页”按钮，直接浏览更多内容。
4. 如需调整脚本设置，可在浏览器油猴菜单中操作。
