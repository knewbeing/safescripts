## 功能介绍

该脚本可以解除大多数网站对复制、剪切、选择文本和右键菜单的限制，让用户自由操作网页内容。

## 适用网站

## 使用方法

1. 安装 Tampermonkey 插件。
2. 在 Tampermonkey 中添加此脚本。
3. 刷新或重新打开需要解除限制的网站。
4. 即可自由复制、剪切、选择文本和使用右键菜单。
