## 功能介绍

此脚本在浏览 GitHub 仓库页面时，显示仓库数量信息，方便用户快速了解当前页面的仓库统计。无需额外操作，自动增强页面显示。

## 适用网站

- GitHub

## 使用方法

1. 安装脚本后，访问 GitHub 网站。
2. 在仓库页面即可看到仓库数量信息自动显示。
