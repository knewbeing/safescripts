## 功能介绍

本脚本可以将 GitHub 网站的部分菜单和内容翻译为中文，让界面更适合中文用户使用。安装后，常见的英文界面元素会自动变为中文，无需手动切换。适用于 GitHub 及其相关子站点。

## 适用网站

- GitHub
- GitHub Skills
- Gist
- GitHub Status

## 使用方法

1. 1. 安装脚本后，访问 GitHub 或相关页面。
2. 2. 页面菜单和部分内容会自动显示为中文。
3. 3. 如需调整设置，可通过油猴菜单进行操作。
