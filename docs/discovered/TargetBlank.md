## 功能介绍

本脚本让网页上的所有链接都在新标签页打开，避免当前页面被覆盖。适用于绝大多数网站，提升浏览体验。

## 适用网站

- 所有网站（除谷歌账号登录页）

## 使用方法

1. 安装脚本后，访问任意网页。
2. 点击网页中的任何链接，都会在新标签页打开。
3. 无需额外设置，自动生效。
