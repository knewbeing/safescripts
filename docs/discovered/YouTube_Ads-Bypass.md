本脚本可自动跳过YouTube和YouTube音乐上的视频广告，并隐藏页面上的横幅、覆盖层和促销等干扰元素，让你观看视频时更加清爽。无需手动操作，广告会自动被屏蔽。

- YouTube音乐

## 使用方法

1. 1. 安装脚本后，打开YouTube或YouTube音乐网站。
2. 2. 视频广告会自动跳过，页面广告元素会自动隐藏。
3. 3. 无需额外设置，直接享受无广告体验。
