本脚本帮助玩家在 Torn City 游戏中快速定位和浏览城市地图上的物品，无需 API 密钥。它会在地图页面显示一个面板，方便切换和查看所有可拾取物品的位置。

## 使用方法

1. 安装脚本后，进入 Torn City 的城市地图页面。
2. 页面会出现一个物品查找面板。
3. 使用面板上的按钮浏览和定位地图上的物品。
