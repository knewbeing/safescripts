本脚本让你在网页上选中文字后，快速通过谷歌、影视、番号等搜索引擎进行搜索。界面适配手机和电脑，操作简单，搜索按钮以链接形式展示。

## 使用方法

1. 安装脚本后，打开任意HTTPS网页。
2. 用鼠标或手指选中你想搜索的文字。
3. 弹出的搜索菜单会显示不同搜索选项。
4. 点击对应链接即可跳转到相关搜索结果页面。
