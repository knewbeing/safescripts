## 功能介绍

自动将下一页内容无缝加载到网页底部，实现类似瀑布流的无限滚动，无需手动点击“下一页”。适用于多种网站，提升浏览体验。部分购物、视频等网站已排除，不会影响。

## 适用网站

- 各类论坛
- 社交网站
- 游戏网站
- 漫画网站
- 小说网站
- 学术网站
- 搜索引擎（如Google、Bing、Yahoo）
- 其他大多数网页（部分购物、视频、特定网站除外）

## 使用方法

1. 安装脚本后，访问支持的网站。
2. 向下滚动页面，下一页内容会自动加载到底部。
3. 无需手动点击“下一页”按钮。
4. 如需调整设置，可在油猴菜单中找到相关选项。
